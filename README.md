### Prerequisites

* Maya

<p align="right">(<a href="#readme-top">back to top</a>)</p>



### Installation

1. Download the latest release zip from the [releases page][releases-url].
2. Extract the zip, then drag the `locatorcreator_drag_and_drop_installer.py` file into a Maya viewport.
3. Restart Maya.
4. Import the module and use the `create_locator` function.
    ```python
    from locatorcreator.example import create_locator

    create_locator("foo")
    ```
5. Enjoy the locators!
